Entry for the make.fun bounty **Make the AI Judge Laugh: Office Jokes**. `main.ts` scores a shortlist of office jokes against the judge brief — a genuine one-line office joke, a real turn at the end, recognition, tight wording, freshness — and writes the winning line (125 characters) to `/output/entry.txt`. The pick is deterministic: every run writes byte-identical output.

The winning joke: hiding behind a calendar status, then getting invited to a meeting about why you are always in meetings.

## Run it

```sh
node main.ts
```
